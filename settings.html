How to get a client ID
  1. Open the Google Cloud console and create or pick a project.
  2. Enable the Google Calendar API for it.
  3. On the OAuth consent screen, add your own Google account as a test user. The calendar scope is a sensitive one, so an app in testing mode only works for listed users.
  4. Under Credentials, create an OAuth client ID with application type Desktop app. There is no redirect URI to fill in — a desktop client is allowed to use a loopback address, which is what Slime listens on.
  5. Paste the client ID and secret below.

Slime asks for read-only access to calendar events and nothing else. It cannot change your calendar.
