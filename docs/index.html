Slime

A small desk pet for Windows that sits on top of your screen and eats the windows you want rid of.

Privacy policy  ·  Terms of service

What it does

  • Lives as a transparent always-on-top overlay, so it shares the desktop rather than occupying a window. Clicks pass straight through it except where the pet actually is.
  • Hold it still over a window for two seconds and it latches on, wraps itself over the window across three seconds, and swallows it. The window closes when the animation finishes, so pulling the slime off it at any point calls the meal off.
  • It escalates to killing a process only when Windows itself reports the app as not responding, and only if you click a second time to say so.
  • You can drag it around and throw it. The body is a soft-body physics simulation rather than a sprite sheet, so it squashes on landing and stretches when flung.
  • It falls asleep when left alone, and the render loop stands down with it.
Everything runs on your own machine. There is no Slime server, no account to create, no telemetry, and no network request of any kind. The privacy policy has the specifics.

Requirements

  • Windows 10 or 11 — it uses the WebView2 runtime that Windows already ships
